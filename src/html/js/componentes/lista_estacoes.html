Estação é onde o laser está montado. Leitura é cada ponto onde você põe a régua. As curvas de nível usam as leituras (no mínimo 3). A primeira leitura vale zero; toque em outra para fazer dela o zero.

Toque no nome de uma estação para o mapa e as curvas usarem só os pontos dela; toque de novo para ver todas.
